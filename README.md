# My Favorite Series: Food Wars! (Shokugeki no Soma)

## Overview
Food Wars is an anime about cooking battles where students compete in intense culinary showdowns.

## Why I Like It
- Exciting cooking battles  
- Creative dishes  
- Interesting characters  

## Main Characters
1. Soma Yukihira  
2. Erina Nakiri  
3. Megumi Tadokoro  

## Favorite Quote
> "The moment you think you’ve got it all figured out, you stop growing."
